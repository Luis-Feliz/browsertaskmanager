Welcome to TimeDoc

Description: This is a website made with the sole intent of providing a simple and effective way to manage my tasks and projects.

How does it work?

TimeDoc is a task management system that allows you to create projects and subtasks. Each subtask can be tracked with a timer, allowing you to monitor the time spent on each task. You can also mark tasks as complete and view your progress.

Features:

  • Create and manage projects
  • Add subtasks to each project
  • Track time spent on each subtask with a timer
  • Mark tasks as complete and view progress

Getting Started:

To get started, simply navigate to the Projects page and create a new project. From there, you can add subtasks and start tracking your time. You can also view your progress and mark tasks as complete.
